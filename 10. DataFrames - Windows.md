# Ventanas de tiempo - Windows

Spark SQL provee de las siguientes window functions:
- cume_dist
- dense_rank
- lag
- lead
- ntile
- percent_rank
- rank
- row_number

Aggregate y funciones window se aplican a una especificación de window

Siendo tales especificaciones las siguientes:
- Particionar columna
- Ordernar columna
- Especificación de fila

## Ejemplo 1: Suma y recuento acumulativo

1. Crea un DataFrame sencillo

```python
df = spark.range(10)
df.show()
```
---
<br>

2. Create una window specification

```python
from pyspark.sql.window import Window

ws = Window.rowsBetween( \                           # Se mueve por filas  
                        Window.unboundedPreceding, \ # desde el principio del conjunto de filas
                        Window.currentRow)           # hasta la fila actual
```
---
<br>

3. La window specification para calcular el recuento y el sumatorio acumulado

```python
from pyspark.sql.functions import count, sum

df.select("id", \
        count("id").over(ws).alias("cum_cnt"), \ # Cuenta las filas 
        sum("id").over(ws).alias("cum_sum")) \   # Va sumando el valor actual al sumatorio
        .show()
```
---
<br>

4. El resultado esperado sería:

|id  | cum_cnt | cum_sum|
|:--:|:-------:|:------:|
|0   |    1    |    0   |
|1   |    2    |    1   |
|2   |    3    |    3   |
|3   |    4    |    6   |
|4   |    5    |   10   |
|... |   ...   |   ...  |
|9   |    10   |   45   |

## Ejemplo 2: Calcular promedio de días entre `rides` por cada `rider`

1. Crear una window specification

```python
ws = Window.partitionBy("rider_id") \ # Se crea una ventana por cada rider
            .orderBy("date_time")     # Y se ordenan los registros por 'date_time' de sus viajes
```
`partitionBy()` permite realizar operaciones por cada usuario individualmente, siguiendo el orden temporal de sus viajes

---
<br>

2. Usamos la función `lag()` para extraer la fecha y hora del viaje anterior

```python
from pyspark.sql.functions import lag

rides2 = rides.withColumn("date_time_previous", lag("date_time").over(ws))

rides2.select("rider_id", "date_time", "date_time_previous").show(truncate=False)

# El viaje previo al primer rider será NULL 
```
Ejemplo:
|rider_id |      date_time      | date_time_previous |
|---------|     -----------     |------------------- |
|1        | 2024-01-01 08:00:00 | NULL               |
|1        | 2024-01-05 09:30:00 | 2024-01-01 08:00:00|
|2        | 2024-01-03 11:00:00 | NULL               |

---
<br>

3. Calcula el número de días entre viajes consecutivos

```python
from pyspark.sql.functions import datediff

rides3 = rides2.withColumn("days_between_rides", datediff("date_time", "date_time_previous"))

rides3.select("rider_id", "date_time", "date_time_previous", "days_between_rides").show(truncate=False)
```
|rider_id |      date_time      | date_time_previous  | days_between_rides|
|---------|---------------------|---------------------|-------------------|
|1        | 2024-01-01 08:00:00 | NULL                | NULL              |
|1        | 2024-01-05 09:30:00 | 2024-01-01 08:00:00 | 4                 |

---
<br>

4. Calcula la media de días entre viajes como para rider

```python
from pyspark.sql.functions import count, mean
rides4 = rides3 \
  .groupBy("rider_id") \
  .agg(count("*").alias("num_rides"), mean("days_between_rides").alias("mean_days_between_rides"))
```

---
<br>

5. Calcula el top 10 riders tanto al principio, como al final

```python
rides4 \
  .where(rides4.mean_days_between_rides.isNotNull()) \
  .orderBy("mean_days_between_rides") \
  .show(10)

rides4 \
  .orderBy("mean_days_between_rides", ascending=False) \
  .show(10)
```
