# Sliding window aggregation

Se puede agregar datos de eventos ocurridos dentro de un período de tiempo específico, es decir una `window` con un número *n* de de micro-batches. La data entrante debe incluir una columna con el timestamp.


La función `functions.window()` para hacer *window aggregation*. 

Algunos parámetros son:

- `timeColumn` Referencia a la columna que contiene la hora del evento

- `windowDuration` o `slideDuration` Duración de la ventana y frecuencia de creación (especificada como cadenas como "1 minute" o "30 seconds"). slide es opcional

## Ejemplo

- Cuenta los mensajes de estado de los modelos seleccionados cada 10 minutos

- Actualizar el recuento cada cinco minutos

- Usa la columna *timestamp* en los mensajes de Kafka para agruparlos por ventana

```python
kafkaDF = spark.readStream.format("kafka")...

from pyspark.sql.functions import *

modelsTimeDF = kafkaDF.select("timestamp", \
                split(kafkaDF.value, ",")[0].alias("model"))

windowRoninCountsDF = modelsTimeDF. \
                    where(modelsTimeDF.model.startswith("Ronin S")). \
                    groupBy(window("timestamp","10 minutes","5 minutes"),"model"). \ # Línea a destacar
                    count()

windowRoninCountsQuery = windowRoninCountsDF.writeStream. \
                                            outputMode("complete"). \
                                            format("console"). \
                                            start()
```
