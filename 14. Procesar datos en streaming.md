# Procesar datos en streaming

1. Definir un `schema` para dotarle de estructura a los datos que entren

```python
from pyspark.sql.types import *

activationsSchema = StructType([ StructField("acct_num", IntegerType()),
                                 StructField("dev_id", StringType()),
                                 StructField("phone", StringType()),
                                 StructField("model", StringType())])
```

2. Crear un `streaming DataFrame` que lea datos

```python
activationsDF = spark.readStream \
                    .schema(activationsSchema) \
                    .json("file:/tmp/devsh-streaming/")
```
3. Arrancar un `streaming Query` que muestre los datos

```python
activationsQuery = activationsDF.writeStream \
                                .outputMode("append") \
                                .format("console") \
                                .option("truncate","false") \
                                .start()
```
## Formatos de salida

- Console (debugging only) Muestra los datos en la consola
- Memory (debugging only) Guarda los datos en memoria
- File-> Se puede usar la función del formato concreto `csv()`, `parquet()`, `json()`, `orc()` y pasar la ruta como parámetro
- Sockets
- Kafka

## .outputMode

El método `.outputMode()` indica qué resultados se devolverán en cada intervalo

- "complete"-> El conjunto completo
- "append"-> Es el modo por defecto y devuelve sólo los nuevos
- "update"-> Devuelve los nuevos y, además, los que hayan sido modificados

En esta tabla podemos ver qué modos admite cada formato de salida

|Output Formats        | Output Mode     |
|---------------       |------------     |
|File                  | append          |
|Console               | all             |
|Foreach, ForeachBatch | all             |
|Kafka                 | all             |
|Memory                | append, complete|

## Streaming Query

Las funciones más comunes son las siguientes

- `.stop()` Finaliza el stream
- `.status()` Devuelve el estado actual
- `.awaitTermination()` Queda a la espera de ser detenido manualmente o cuando ocurra una excepción

## Ejemplo tomando una muestra y devolviéndola a un CSV cada 3 segundos

```python

titanic1000DF = activationsDF.where("model = 'Titanic 1000'") \
                             .select("dev_id","acct_num")

titanic1000Query = titanic1000DF.writeStream \
                                .trigger(processingTime="3 seconds") \
                                .outputMode("append") \
                                .format("csv") \
                                .option("path","/user/training/titanic1000/") \
                                .start()
```
