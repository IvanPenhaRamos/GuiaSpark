# Combining and Splitting DataFrames

## Joins

Joins are expensive in the big-data world
- Perform joins early in the process
- Amortize the cost over many use cases

**Cross join**

El método `crossJoin()` hace un join de toda columna del DF de la izquierda con toda columna del DF de la derecha

Crea un producto cartesiano y las columnas con el mismo nombre no se renonmbran.

```python
scientists.crossJoin(offices).show()
```

**Inner join**

Introduce `"inner"` como parámetro del método `join()`para devolver las filas que cumplan con el seungdo parámetro 
```python
scientists.join(offices, scientists("office_id") === offices("office_id"), "inner").show()
```
Si el nombre de la columna coincide en ambos DFs, se puede simplificar así:
```python
scientists.join(offices, "office_id").show()
```

**Left semi join**

Para que nos devuelva los valores del DF de la izquierda que coincidan con el de la derecha usaremos `left_semi` como parámetro

```python
scientists.join(offices, scientists("office_id") === offices("office_id"), "left_semi").show()
```
**Left anti join**

Para que nos devuelva los valores del DF de la izquierda que **NO** coincidan con el de la derecha usaremos `left_anti` como parámetro
```python
scientists.join(offices, scientists("office_id") === offices("office_id"), "left_anti").show()
```
**Left outer join**

Usa el parámetro `left` o `left_outer` para que nos devuelva todas las filas de la izquierda coincidan o no con el DF de la derecha
```python
scientists.join(offices, scientists("office_id") === offices("office_id"), "left_outer").show
```
**Right outer join**

Usa el parámetro `right` o `right_outer` para que nos devuelva todas las filas de la derecha coincidan o no con el DF de la izquierda
```python
scientists.join(offices, scientists("office_id") === offices("office_id"), "right_outer").show
```
**Full outer join**

Los parámetros `full`, `outer`, o `full_outer` nos devolverán la unión de un *left outer* y un *right outer* eliminando los duplicados
```python
scientists.join(offices, scientists("office_id") === offices("office_id"), "full_outer").show
```

## Operaciones de conjuntos o sets a los DataFrames

Spark SQL proporciona los siguientes métodos de DataFrame que implementan operaciones de conjuntos:

- Union
- Intersection
- Substracion

### Union 

El método `union()` une las filas de dos DFs con un esquema similar
```python
driver_names = drivers.select("first_name")
driver_names.count()

rider_names = riders.select("first_name")
rider_names.count()

names_union = driver_names.union(rider_names).orderBy("first_name")
names_union.count()
names_union.show()
```

Hay que tener en cuenta que `union()` no elimina duplicados. Se debería aplicar el método `distinct()` para que lo hiciera

```python
names_distinct = names_union.distinct()
```

### Intersect

El método `intersect()` obtiene las filas que existen en ambos DataFrames.

```python
name_intersect = driver_names.intersect(rider_names).orderBy("first_name")
```
### Subtract

El método `subtract()` obtiene las filas del DataFrame izquierdo que no existen en el DataFrame derecho.

```python
names_subtract = driver_names.subtract(rider_names).orderBy("first_name")
```

## Splitting a DataFrame

El método `randomSplit()` separa el DF en submuestras aleatorias. 
```python
riders.count()
(train, validate, test) = riders.randomSplit(weights=[0.6, 0.2, 0.2])
(train.count(), validate.count(), test.count())
```
Se puede usar el parámetro `seed` para garantizar la replicabilidad.
```python
(train, validate, test) = riders.randomSplit([0.6, 0.2, 0.2], seed=12345)
(train.count(), validate.count(), test.count())
```
