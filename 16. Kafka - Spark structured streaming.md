# Kafka en Spark

Cada mensaje recibido de Kafka en un elemento del DF

Es necesario especificar el modo de subscripción al topic mediante parámetro del método `option()`:

- subscribe -> Si es más de un topic al que se desea suscribir, se separa con coma
- subscribePattern -> Busca los topic que coincidan con una expresión regex
- assign -> Se indica mediante un JSON strin la partición específica del topic


Todos los DataFrames de Kafka van a tener el mismo esquema

- key -> **Binario** Puede estar vacío y se puede usar para organizar o clasificar mensajes
- value -> **Binario** Contenido como tal del mensaje
- topic -> **String**
- partition -> **Integer**
- offset -> **Long**
- timestamp
- timestampType

El productor elige el formato, pero suelen ser CSV, JSON o el formato de Avro. Debe transformarse en un formato legible.

## Ejemplo de un CSV entrante

1. Lee el topic
```python
kafkaDF = spark.readStream. \
                format(“kafka”). \
                option("kafka.bootstrap.servers","broker-host1:9092,broker-host2:9092"). \
                option("subscribe","status"). \
                load()
```
2. Trocea el mensaje con `split()`
```python
from pyspark.sql import functions

valuesDF = kafkaDF.select(functions.split(kafkaDF.value, ",").alias("status_vals"))
```
3. Escoge las columnas que se van a usar y las transforma
```python
modelTempsDF = valuesDF.
               select(valuesDF.status_vals[0].alias("model"),
                      valuesDF.status_vals[2].cast("integer").alias("dev_temp"))
```

## Ejemplo de un CSV saliente

1. Da formato al DF que quieras emitir como un KVP. En este caso la clave está vacía.

```python
statusDF = ...

from pyspark.sql import functions

statusValueDF = statusDF. \
                select(functions.lit("").alias("key"), \
                       functions.concat_ws(",","dev_id","model").alias("value"))
```
2. Ponemos en streaming el DF formateado en una query

```python
statusValueQuery = statusValueDF.writeStream. \
                            format("kafka"). \
                            option("checkpointLocation","/tmp/kafka-checkpoint"). \
                            option("topic","status-out"). \
                            option("kafka.bootstrap.servers","brokerhost:9092"). \ # ( "broker" , "puerto" )
                            start()
```

## Ejemplo de streaming con Kafka usando JSON

### Consumer

1. Desde CLI crea el topic `activations`

```sh
kafka-topics --create  \
--bootstrap-server localhost:9092 \
--partitions 2 \
--replication-factor 1 \
--topic activations
```

2. Crea el *consumer*, un streaming DataFrame que se subscriba a `activations`

```python
kafkaDF = spark.readStream. \
                format("kafka"). \
                option("kafka.bootstrap.servers", "localhost:9092"). \
                option("subscribe", "activations"). \
                load()
```
 
3. Crea otro DataFrame para aislar el contenido del mensaje (alojado siempre en el Value del KVP)

```python
stringValueDF = kafkaDF.select(kafkaDF.value.cast("string"))
```


4. Define el esquema para mapear el JSON y transformarlo en columnas

```python
from pyspark.sql.types import * 

activationsSchema = StructType([StructField("acct_num", IntegerType()),
                                StructField("dev_id", StringType()),
                                StructField("phone", StringType()),
                                StructField("model", StringType())])
```     
5. Usa la función `from_json` para aplicar el esquema a la columna `value` del DataFrame

```python                               
from pyspark.sql.functions import *

activationsDF = stringValueDF.select(from_json(stringValueDF.value,activationsSchema).alias("activation"))
```

6. Crea la query para activar el streaming

```python
activationsQuery = activationsDF.writeStream. \
                                outputMode("append"). \
                                option("truncate","false"). \
                                format("console"). \
                                start()
```

### Producer

1. Crea un topic al que volcar mensajes desde el CLI

```sh
kafka-topics \
--create \
--bootstrap-server localhost:9092 \
--partitions 2 \
--replication-factor 1 \
--topic activations-out
```

2. Desde la misma ventana del CLI arranca el `consumer` para comprobar

```sh
kafka-console-consumer \
--topic activations-out \
--bootstrap-server localhost:9092 \
--from-beginning
```

3. Crea el esquema para mapear el JSON a columnas

```python
from pyspark.sql.types import *

activationsSchema = StructType([ StructField("acct_num", IntegerType()),
                                StructField("dev_id", StringType()),
                                StructField("phone", StringType()),
                                StructField("model", StringType())])
```

4. Crea el streaming DataFrame

```python
activationsDF = spark.readStream. \
                    schema(activationsSchema). \
                    option("maxFilesPerTrigger",1). \
                    json("Ruta/de/la/data")
```

5. Da formato de mensaje de Kafka al streaming DataFrame entrante

```python
from pyspark.sql.functions import *

activationsValueDF = activationsDF.select(lit("").alias("key"), \
                                        concat_ws(",",activationsDF.acct_num,activationsDF.dev_id).alias("value"))
```

6. Crea el query para producir los mensajes

```python
activationsKafkaQuery = activationsValueDF.writeStream. \
                                        format("kafka"). \
                                        option("checkpointLocation","/tmp/kafka-checkpoint"). \
                                        option("topic","activations-out"). \
                                        option("kafka.bootstrap.servers","localhost:9092"). \
                                        start()
```
