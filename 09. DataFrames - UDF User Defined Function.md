# User-Defined Functions (UDF)

1. Crear una función en el lenguaje propio. Python en este caso

```python
import datetime

def hour_of_day(timestamp):
  return timestamp.hour
```

2. Registra la función de Python como una UDF mediante su propia función `udf()`. 

```python
from pyspark.sql.functions import udf
from pyspark.sql.types import IntegerType

hour_of_day_udf = udf(hour_of_day, returnType=IntegerType()) # StringType por defecto, pero parametrizable
```

3. Utiliza la función como si fuera una función integrada

```python
rides_clean \
  .select("date_time", hour_of_day_udf("date_time")) \
  .show(5, truncate=False)
```

## Aspectos a tener en cuenta

- Python y cualquier paquete que se use debe estar instalados en los worker nodes.
    - Es posible distribuir los paquetes necesarios a través de Spark.
- Las funciones integradas son más eficientes que las definidas por el usuario, por lo que se debe priorizar su uso por los siguientes motivos:
    - Se debe iniciar un proceso de Python junto con cada ejecutor.
    - Los datos deben convertirse entre tipos de Java y Python.
    - Los datos deben transferirse entre los procesos de Java y Python.
- Para mejorar el rendimiento de una UDF:
    - Use la plataforma [Apache Arrow](https://arrow.apache.org/).
    - Use una UDF vectorizada (como la función pandas_udf).
    - Reescriba la UDF en Scala o Java.
