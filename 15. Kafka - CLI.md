# Kafka - CLI

Lista de los topics
```sh
kafka-topics --list --zookeeper zkhost1:2181,zkhost2:2181,zkhost3:2181
```
Para ayuda
```sh
kafka-topics --help
```
Para conectarse a un topic como:

- Producer->`kafka-console-producer`

- Consumer->`kafka-console-consumer`
```sh
kafka-console-producer \
--broker-list brokerhost1:9092,brokerhost2:9092 \
--topic device_status
```
Ejemplo en el que lee un archivo de texto y transforma cada línea de texto en un mensaje del topic
```sh
cat alerts.txt | kafka-console-producer \
--broker-list brokerhost1:9092,brokerhost2:9092 \
--topic device_status
```
Puedes usar `--from-beginning` para leer los mensajes "desde el principio" del topic, si no, sólo leerá los nuevos
```sh
kafka-console-consumer \
--bootstrap-server brokerhost:9092 \
--topic device_status \
--from-beginning
```
