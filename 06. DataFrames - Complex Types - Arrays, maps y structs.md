# Complex Collection Data Types

Complex collection data types provide a way to renormalize the denormalized data that is common in the big-data world

The complex collection data types are defined in the pyspark.sql.types module:

- *ArrayType* represents a variable-length collection of elements
- *MapType* represents a variable-length collection of key-value pairs
- *StructType* represents a fixed-length collection of named elements

Los tipos de colecciones complejas de datos se obtienen de muchas maneras:

- Heredadas de tablas Hive o Impala
- Inferidas de los archivos JSON anidados
- Generados por funciones agredadoras como `collect_list` o `collect_set`
- Construidas manualmente

## Arrays

La función `array()` crea un array de múltiples columnas

El método `.withColumn()` toma como:

1. Primer parámetro-> el nombre del array
2. Segundo parámetro-> la función y las columnas a unir

```python
from pyspark.sql.functions import array

drivers_array = drivers \
        .withColumn("vehicle_array", array("vehicle_make", "vehicle_model")) \
        .select("vehicle_make", "vehicle_model", "vehicle_array")
```
Se puede indicar el índica para acceder a los elementos del array

```python
from pyspark.sql.functions import col

drivers_array \
  .select("vehicle_array", col("vehicle_array")[0]) \
  .show(5, False)
```

La función `size()` para obtener la longitud del array

```python
from pyspark.sql.functions import size

drivers_array \
  .select("vehicle_array", size("vehicle_array")) \
  .show(5, False)
```

La función `sort_array()` organiza la colección.
Como segundo parámetro, `asc` o `desc`

```python
from pyspark.sql.functions import sort_array

drivers_array \
  .select("vehicle_array", sort_array("vehicle_array", asc=True)) \
  .show(5, False)
```

La función `array_contains` busca en el array el elemento que indiquemos por parámetro

```python
from pyspark.sql.functions import array_contains

drivers_array \
  .select("vehicle_array", array_contains("vehicle_array", "Subaru")) \
  .show(5, False)
```

La función `explode()` separa los elementos del array.
La función `posexplode()` indica además la posición dentro del array

```python
from pyspark.sql.functions import explode, posexplode

drivers_array \
  .select("vehicle_array", explode("vehicle_array")) \
  .show(5, False)

#Aquí usamos el método .alias() para nombrar ambas columnas

drivers_array \
  .select("vehicle_array", posexplode("vehicle_array").alias("position", "column")) \
  .show(5, False)
```

## Maps

Los *Maps* son colecciones de pares clave/valor (KVP)

La función `create_map()` crea el map

```python
from pyspark.sql.functions import lit, create_map

drivers_map = drivers \
    .withColumn("vehicle_map", create_map(lit("make"), "vehicle_make", lit("model"), "vehicle_model")) \
    .select("vehicle_make", "vehicle_model", "vehicle_map")
```

Se puede usar la nomenclatura del punto para acceder al valor por la clave

```python
drivers_map.select("vehicle_map", col("vehicle_map").make).show(5, False)

#En este caso utiliza .make porque es el nombre que se le dio previamente mediante lit()
```

La función `size()` nos da la longitud del map. Por lo general `2` al ser un KVP.

```python
drivers_map.select("vehicle_map", size("vehicle_map")).show(5, False)
```

Las funciones `explode()` y `posexplode()` para *explotar* el map
y añadir la posición en el caso del segundo

```python
drivers_map.select("vehicle_map", explode("vehicle_map")).show(5, False)

drivers_map.select("vehicle_map", posexplode("vehicle_map")).show(5, False)
```

## Structs

Los `struct` son objetos Row y está embebido en el propio objeto Row.

```python
from pyspark.sql.functions import struct

drivers_struct = drivers \
  .withColumn("vehicle_struct", struct(col("vehicle_make").alias("make"), col("vehicle_model").alias("model"))) \
  .select("vehicle_make", "vehicle_model", "vehicle_struct")
```

Nomeclatura del punto para acceder a los elementos del struct

```python
drivers_struct \
  .select("vehicle_struct", col("vehicle_struct").make) \
  .show(5, False)
```

La función `to_json` convierte el struct a un string JSON

```python
from pyspark.sql.functions import to_json

drivers_struct \
  .select("vehicle_struct", to_json("vehicle_struct")) \
  .show(5, False)
```
