# Summarizing data with aggregate functions

## Resumiendo datos con funciones de agregación

El método `describe()` proporciona estadística básicas del DataFrame

```python
rides.describe("distance").show()
```
|summary|"distance"|
|-------|:--------:|
|count  |    X     |
|mean   |    X     |
|stddev |    X     |
|min    |    X     |
|max    |    X     |

Las funciones `count()`, `countDistinct()` y `approx_count_distinct()` para calcular el número de columnas.

```python
from pyspark.sql.functions import count, countDistinct, approx_count_distinct

rides.select(count("*"), count("distance"), countDistinct("distance"), approx_count_distinct("distance")).show()
```

El `count()` incluye el número de columnas con valores no nulos.
Es preferible utilizar count(lit(1)) en lugar de count(1) como alternativa a count("*").

<br>

---

El método agg devuelve los mismos resultados y se puede aplicar a datos agrupados.

```python
rides.agg(count("*"), count("distance"), countDistinct("distance"), approx_count_distinct("distance")).show()
```
<br>

---

Las funciones `sum()` y `sumDistinct()` para sumar los valores de columnas completas

```python
from pyspark.sql.functions import sum, sumDistinct

rides.agg(sum("distance"), sumDistinct("distance")).show()
```
<br>

---
Spark SQL provée de unas funciones estadísticas básicas para resumir como:

- `mean()` Media: Valor promedio de un conjunto de datos
- `stddev()` Standard deviation -> Desviación estándar: Mide cuánto se dispersan los datos con respecto a la media.
- `variance()` Varianza: : Promedio de las diferencias al cuadrado respecto a la media. Mide la variabilidad de los datos y la desviación estándar es la raíz cuadrada de la varianza.
- `skewness()` Asimetría / Sesgo: Indica si la distribución está sesgada hacia un lado. Si 0, simetría (campana perfecta); si negativo, cola hacia la izquierda; si positivo, hacia la derecha
- `kurtosis()` Curtosis:  Mide la "altura" y forma de la cola de la distribución en comparación con una distribución normal.

```python
from pyspark.sql.functions import mean, stddev, variance, skewness, kurtosis

rides.agg(mean("distance"), stddev("distance"), variance("distance"), skewness("distance"), kurtosis("distance")).show()
```
<br>

---
Utilice las funciones `min()` y `max()` para calcular el mínimo y el máximo, respectivamente.

```python
from pyspark.sql.functions import min, max

rides.agg(min("distance"), max("distance")).show()
```
<br>

---
Utilice las funciones `first()` y `last()` para calcular el primer y el último valor, respectivamente.

Los valores nulos se ordenan antes que los valores numéricos válidos

```python
from pyspark.sql.functions import first, last

rides \
  .orderBy("distance") \
  .agg(first("distance", ignorenulls=False), last("distance", ignorenulls=False)) \
  .show()
```
<br>

---

Utilice las funciones `corr()`, `covar_samp()` o `covar_pop()` para medir la asociación lineal entre dos columnas.

```python
from pyspark.sql.functions import corr, covar_samp, covar_pop

rides \
  .agg(corr("distancia", "duración"), covar_samp("distancia", "duración"), covar_pop("distancia", "duración")) \
  .show()
```

Las funciones `collect_list()` y `collect_set()` devuelven una columna de tipo array.

`collect_list()` no elimina los duplicados y, en este caso, devolverá un array muy largo

```python
from pyspark.sql.functions import collect_list, collect_set

rides.agg(collect_set("service")).show(truncate=False)
```

## Grouping data

El método `agg()` con el método `groupBy()` para refinar su análisis.

```python
rides \
  .groupBy("rider_student") \
  .agg(count("*"), count("distance"), mean("distance"), stddev("distance")) \
  .show()
```
<br>

---
Puede usar más de una columna en el método `groupBy()`.
```python
rides \
  .groupBy("rider_student", "service") \
  .agg(count("*"), count("distance"), mean("distance"), stddev("distance")) \
  .orderBy("rider_student", "service") \
  .show()
```

<br>

---
El método `rollup()` para obtener subtotales
```python
rides \
  .rollup("rider_student", "service") \
  .agg(count("*"), count("distance"), mean("distance"), stddev("distance")) \
  .orderBy("rider_student", "service") \
  .show()
```

<br>

---
La función `grouping()` para identificar filas agrupadas
```python
from pyspark.sql.functions import grouping

rides \
  .rollup("rider_student", "service") \
  .agg(grouping("rider_student"), grouping("service"), count("*"), count("distance"), mean("distance"), stddev("distance")) \
  .orderBy("rider_student", "service") \
  .show()
```

<br>

---
El método `cube()`para obtener subtotales
```python
rides \
  .cube("rider_student", "service") \
  .agg(count("*"), count("distance"), mean("distance"), stddev("distance")) \
  .orderBy("rider_student", "service") \
  .show()
```

<br>

---
Utilice la función `grouping_id()` para identificar filas agrupadas.
```python
from pyspark.sql.functions import grouping_id

rides \
  .cube("rider_student", "service") \
  .agg(grouping_id("rider_student", "service"), count("*"), count("distance"), mean("distance"), stddev("distance")) \
  .orderBy("rider_student", "service") \
  .show()
```

## Pivoting data

El siguiente ejemplo es el uso común
```python
rides \
  .groupBy("rider_student", "service") \
  .count() \
  .orderBy("rider_student", "service") \
  .show()
```
<br>

---
El método `crosstab()` se puede usar para mostrar el resultado en una tabla pívot
```python
rides.crosstab("rider_student", "service").show()
```
<br>

---
También podemos usar el método `pivot()` para generar una tabulación cruzada (cross-tabulation)
```python
rides \
  .groupBy("rider_student") \
  .pivot("service") \
  .count().show()
```
<br>

---
También podemos realizar otras agregaciones:
```python
rides \
  .groupBy("rider_student") \
  .pivot("service") \
  .mean("distance") \
  .show()

rides \
  .groupBy("rider_student") \
  .pivot("service") \
  .agg(mean("distance")) \
  .show()
```
<br>

---
Puede elegir explícitamente los valores que se pivotan a las columnas:

```python
rides \
  .groupBy("rider_student") \
  .pivot("service", ["Car", "Grand"]) \
  .agg(mean("distance")) \
  .show()
```
<br>

---
Las funciones de agregación adicionales generan columnas adicionales.
```python
rides \
  .groupBy("rider_student") \
  .pivot("service", ["Car"]) \
  .agg(count("distance"), mean("distance")) \
  .show()
```
