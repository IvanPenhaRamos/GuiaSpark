# Spark

La aplicación se debe empezar creando la sesión con el objeto `SparkSession` y un `SparkContext` que se crear automáticamente con el objeto `.builder`

```python
from pyspark.sql import SparkSession

spark = SparkSession.builder \
                    .appName('prueba_spark') \
                    .master("local[*]") \ # Donde queremos que se ejecute (local, YARN, K8S, etc)
                    .getOrCreate() # Esta función devuelve el objeto de la sesión si existiera
```

El método `setLogLevel` indica que nos mostrará los logs a partir de Warn (warn y error)

```python
spark.sparkContext.setLogLevel("WARN")
```

A la hora de crear una aplicación conviene *cerrar* la sesión 

```python
spark.stop()
```

El comando para ejecutar la aplicación desde el CLI
```sh
spark-submit /path/De/La/App.py
```

## Ejemplo de aplicación en PySpark

```python
import sys
from pyspark.sql import SparkSession

# Se asegura que se ejecuta desde dentro del aplicativo
if __name__ == "__main__":

# Se asegura que se recibe el mínimo de argumentos
    if len(sys.argv) < 3:
        print >> sys.stderr,
            "Usage: NameList.py <input-file> <output-file>"
    sys.exit()

# Crea la sesión
spark = SparkSession.builder.getOrCreate()

# Crea el contexto y establece el nivel de log en WARN
spark.sparkContext.setLogLevel("WARN")

# Cuerpo de la aplicación

## Lee un JSON indicado como argumento
peopleDF = spark.read.json(sys.argv[1])

## Selecciona nombre y apellido
namesDF = peopleDF.select("firstName","lastName")

## Lo vuelva en un CSV en la ruta que se indique como segundo argumento
namesDF.write.option("header","true").csv(sys.argv[2])

# Cierra la sesión
spark.stop()
```

## Ejempo de aplicación en Scala

```scala
import org.apache.spark.sql.SparkSession

object NameList {
    def main(args: Array[String]) {
    
    if (args.length < 2) {
        System.err.println(
        "Usage: NameList <input-file> <output-file>")
    } System.exit(1)

    val spark = SparkSession.builder.getOrCreate()
    spark.sparkContext.setLogLevel("WARN")

    val peopleDF = spark.read.json(args(0))
    val namesDF = peopleDF.select("firstName","lastName")
    namesDF.write.option("header","true").csv(args(1))
    spark.stop
    }
}
```
